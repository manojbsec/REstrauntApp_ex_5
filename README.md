# REstrauntApp
AIM :

To design a website for a Restaurant of your choice.

Submission:

Mention the GitHub Repo URL, Website URL in the submission text and attach the lab report pdf.
[restaurant link](http://127.0.0.1:8000/static/index.html)

Note:  

Create a website with a minimum of four menus and add the following additional information

1) Home page must be exactly like the sample page given below.

2) Display at least twelve food items on the MENU page.

3) Add six people with photos and designations on the ADMINISTRATION page.

4) Add contact address with phone and e-mail on the CONTACT US page.

5) Change the banner image and color scheme.

6) Mention your name in the footer.

7) Choose the appropriate color scheme and mention it in the report.

8) External library/frameworks are not allowed, Write your own HTML and CSS.
